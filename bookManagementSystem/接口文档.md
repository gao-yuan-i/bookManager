# 图书管理系统接口文档

**Base URL:** `http://localhost:8080`

> 除登录和注册外，所有接口需在请求头携带 Token：`Authorization: Bearer <token>`

---

## 一、认证模块 — AuthController

### 1. 用户注册

**POST** `http://localhost:8080/api/register`

请求体（JSON）：

```json
{
  "username": "testuser",
  "password": "123456",
  "realName": "张三",
  "phone": "13800138000",
  "email": "zhangsan@example.com"
}
```

curl 示例：

```bash
curl -X POST http://localhost:8080/api/register \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"123456","realName":"张三","phone":"13800138000","email":"zhangsan@example.com"}'
```

说明：`username` 3-50位、`password` 6-20位必填，其余选填。默认角色为普通用户，最大借阅 5 本。

---

### 2. 用户登录

**POST** `http://localhost:8080/api/login`

请求体（JSON）：

```json
{
  "username": "admin",
  "password": "123456"
}
```

curl 示例：

```bash
curl -X POST http://localhost:8080/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'
```

成功响应：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9..."
  }
}
```

## 二、用户端模块 — UserBookController

### 3. 查询图书列表

**GET** `http://localhost:8080/api/user/books?page=1&size=10&keyword=Java&category=编程`

curl 示例：

```bash
curl -X GET "http://localhost:8080/api/user/books?page=1&size=10" \
  -H "Authorization: Bearer <token>"

curl -X GET "http://localhost:8080/api/user/books?page=1&size=10&keyword=Java" \
  -H "Authorization: Bearer <token>"

curl -X GET "http://localhost:8080/api/user/books?page=1&size=10&category=编程" \
  -H "Authorization: Bearer <token>"
```

参数说明：

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| page | 否 | 1 | 页码 |
| size | 否 | 10 | 每页条数 |
| keyword | 否 | | 搜索关键词（匹配书名/作者/ISBN） |
| category | 否 | | 分类筛选 |

### 13. 新增图书

**POST** `http://localhost:8080/api/admin/books`

请求体（JSON）：

```json
{
  "isbn": "978-7-111-00001-1",
  "title": "Java编程思想",
  "author": "Bruce Eckel",
  "publisher": "机械工业出版社",
  "publishDate": "2023-01-01",
  "category": "编程",
  "description": "Java经典入门书籍",
  "coverImage": "https://example.com/cover.jpg",
  "totalQuantity": 10,
  "location": "A区-3排-5号"
}
```

curl 示例：

```bash
curl -X POST http://localhost:8080/api/admin/books \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"isbn":"978-7-111-00001-1","title":"Java编程思想","author":"Bruce Eckel","publisher":"机械工业出版社","publishDate":"2023-01-01","category":"编程","description":"Java经典入门书籍","totalQuantity":10,"location":"A区-3排-5号"}'
```

说明：`title` 必填，`totalQuantity` 至少为 1，其余选填。可用数量自动等于总数量。

---

### 14. 修改图书

**PUT** `http://localhost:8080/api/admin/books/1`

请求体（JSON）：

```json
{
  "isbn": "978-7-111-00001-1",
  "title": "Java编程思想（第4版）",
  "author": "Bruce Eckel",
  "publisher": "机械工业出版社",
  "publishDate": "2024-01-01",
  "category": "编程",
  "description": "Java经典入门书籍第四版",
  "totalQuantity": 15,
  "location": "A区-3排-6号"
}
```

curl 示例：

```bash
curl -X PUT http://localhost:8080/api/admin/books/1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"title":"Java编程思想（第4版）","author":"Bruce Eckel","publisher":"机械工业出版社","totalQuantity":15,"location":"A区-3排-6号"}'
```

说明：修改总数量时，可用数量会同步调整（新可用 = 原可用 + 总数变化量），不会小于已借出数量。

### 18. 新增用户

**POST** `http://localhost:8080/api/admin/users`

请求体（JSON）：

```json
{
  "username": "newuser",
  "password": "123456",
  "realName": "李四",
  "phone": "13700137000",
  "email": "lisi@example.com",
  "role": "USER",
  "maxBorrow": 10
}
```

curl 示例：

```bash
curl -X POST http://localhost:8080/api/admin/users \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"username":"newuser","password":"123456","realName":"李四","phone":"13700137000","email":"lisi@example.com","role":"USER","maxBorrow":10}'
```

说明：`username` 必填。不填密码则默认为 `123456`，不填角色则默认为 `USER`，不填 maxBorrow 则默认为 5。

## 附录：状态码说明

| 字段 | 值 | 含义 |
|------|-----|------|
| 用户 status | 1 | 启用 |
| 用户 status | 0 | 禁用 |
| 图书 status | 1 | 上架 |
| 图书 status | 0 | 下架 |
| 借阅 status | 1 | 借阅中 |
| 借阅 status | 2 | 已归还 |
| 借阅 status | 3 | 已逾期 |
| 角色 | ADMIN | 管理员 |
| 角色 | USER | 普通用户 |
